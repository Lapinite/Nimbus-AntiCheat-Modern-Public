# Security Policy

Nimbus AntiCheat is security-sensitive software. Please do not publish exploit details, bypass methods, proof-of-concept cheating instructions, credentials, private server data, or other information that could create immediate risk.

## Reporting a security issue

If GitHub Private Vulnerability Reporting is available in this repository's **Security** tab, use that option for sensitive reports.

For non-sensitive defects, use the repository's public Issues area when appropriate.

A useful security report should include:

- affected Nimbus product line and version;
- affected Minecraft and server-platform version;
- reproduction conditions;
- expected and observed behavior;
- relevant logs or evidence with secrets removed;
- impact and whether the issue is currently exploitable.

Do not include passwords, access tokens, private keys, player personal data, or other secrets in reports.

The Leviathan Project may ask for additional information before confirming or fixing a report.
